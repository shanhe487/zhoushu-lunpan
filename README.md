# 咒术轮盘 · 朱印轮盘（离线版）

基于 B 站在线版「咒术轮盘」制作的完全离线版本，移除了所有网络依赖和追踪脚本，并新增了**概率实时修改**功能。

## 快速开始

### Windows 用户
双击 `start.bat` 即可自动启动服务器并打开浏览器。

### Mac / Linux 用户
在终端中运行：
```bash
chmod +x start.sh
./start.sh
```

### 手动启动
确保已安装 Python 3，然后在游戏目录下执行：
```bash
python3 -m http.server 8765
```
然后浏览器访问 `http://localhost:8765`

> ⚠️ 必须通过 HTTP 服务器访问，不能直接双击 index.html 打开（浏览器安全限制会导致数据加载失败）。

## 概率修改功能

游戏右上角有一个「🎯 概率控制台」面板：

- **默认收起**：点击面板标题栏可展开/收起
- **实时显示**：当前轮盘每个选项的权重和概率百分比
- **修改权重**：在输入框中修改数值，权重越大概率越高（无需归一化）
- **应用权重**：点击「应用权重」按钮立即生效，转盘扇区面积同步更新
- **恢复默认**：点击「恢复默认」按钮还原当前轮盘所有选项为原始权重
- **自动保存**：所有自定义权重自动保存到浏览器本地，刷新/关闭后仍然有效
- **已修改标记**：被修改过的选项左侧会有金色边框标识

### 使用示例
1. 展开概率控制台
2. 把「普通人」的权重从 8 改成 100
3. 点击「应用权重」
4. 此时普通人的抽取概率从 25.8% 变为 81.3%
5. 点击「转动命运」，大概率会抽到普通人

## 与在线版的区别

| 特性 | 在线版 | 离线版 |
|------|--------|--------|
| 游戏内容 | 完全一致 | 完全一致 |
| 网络依赖 | 需要联网 | 完全离线 |
| 追踪上报 | 有 | 已移除 |
| 概率修改 | 不支持 | ✅ 支持实时修改 |
| 加载速度 | 受网络影响 | 秒开 |

## 注意事项

1. 所有游戏存档和自定义权重都保存在浏览器本地存储中，清除浏览器数据会丢失。
2. 建议使用 Chrome / Edge / Firefox 等现代浏览器。
3. 如果遇到问题，可以按 F12 打开开发者工具查看控制台信息。
4. 本版本仅用于个人离线学习和娱乐，请尊重原作者的创作成果。
